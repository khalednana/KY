# Logo Images

Place your company logo images here.

## Required Logo Files:

1. **`logo.png`** - Main logo for header (dark background)
   - Recommended size: 200x60px or similar aspect ratio
   - Format: PNG with transparent background (preferred)
   - Used in: Header navigation

2. **`logo-white.png`** - White/light logo for hero section (dark background)
   - Recommended size: 600x180px or similar aspect ratio
   - Format: PNG with transparent background (preferred)
   - Used in: Home page hero section

## File Structure:
```
public/images/logo/
  ├── logo.png          (for header - dark logo)
  └── logo-white.png    (for hero - white/light logo)
```

## Notes:
- If you only have one logo, you can use the same file for both (just copy it)
- The logos will automatically scale to fit their containers
- Transparent backgrounds work best for flexibility
- PNG format is recommended for logos with transparency
